# movies-database-system
🎬 Movies Management System

A simple Movies Management System built with HTML, CSS, JavaScript, and SQL Database.

🚀 Features:
 Search movies by title
 Display movie posters, cast, director, producer, language & ratings
 Add new movies dynamically from frontend
 SQL Database for structured movie data storage
 Responsive layout with a clean UI

 Tech Stack:
Frontend: HTML, CSS, JavaScript
Database: SQL (MySQL)

🎯 Purpose:
This project was created to practice:
Building a frontend interface for managing movies
Handling database operations using SQL
Connecting frontend with backend for full-stack development
